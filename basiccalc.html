代入は <- （左辺の変数に右辺を代入）や -> （右辺の変数に左辺を代入）を用いる。 数学で使用するのと同様に = で代入を行うこともできるが，推奨されていない。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. x <- 5
  2. y <- 11
  3. x
  4. y
  5. x - y
  6. x*y
  7. x/y
  8. log(x)
  9. z <- log(x)
  10. z
  11. exp(z)
3，4行

ベクトルと一括計算

R では複数のデータを並べたもの（データセット）をベクトルと呼ぶ。高校で学習したベクトルの概念と似ているが，データに文字データが含まれてもよいし，データの数はいくつでもかまわない。
ベクトルは c(　）の中にコンマで区切って値を書き定義する。数学関数や四則演算にベクトルを使用すると，各成分の計算になる。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. x <- c(1, 2, 3, 4)
  2. x*4
  3. x/4
  4. 4/x
  5. x^2
  6. 3^x
  7. y <- 1/x
  8. y
  9. sin(y)
2～6行
2行は，ベクトルの各成分を4倍する。3～6行も同様で，成分ごとに計算をし，その結果をベクトルとして返す。
7行　y <- 1/x
計算結果を変数 y に代入する。当然 y もベクトルとして定義される。
9行　sin(y)
関数の引数（ひきすう，括弧の中の変数など）がベクトルの場合，ベクトルの各成分を関数の引数として計算したベクトル値が計算される。

ベクトル同士の計算

加減乗除はベクトル同士の演算でも使用できる。これらは成分ごとの演算になる。
x の k 番目の成分は x[k] で，j 番目から k 番目までの成分は x[j:k] で得られる。
その他の処理も以下の通りである。

+ ベクトルの和
- ベクトルの差
* 成分ごとの積
スカラー倍
/ 成分ごとの除算
スカラー除算
%*% 内積
rev 成分の反転
練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. x <- c(2, 3, -4)
  2. y <- c(3, -1, -2)
  3. x + y
  4. x - y
  5. x * y
  6. x / y
  7. x %*% y
  8. rev(x)
  9. x[2]
  10. x[1:2]
3，4行
通常のベクトルの演算。
5，6行
x，yの各成分同士の積，商を並べたベクトルを求める。
7行
xとyの内積を求める。
8行
xの成分を逆に並べたベクトルを求める。
9行
xの第2成分を取り出す。
10行
xの第1成分から第2成分までを並べたベクトルを取り出す。

数列

seq を使って数列を生成することができる。生成された数列は，ベクトルとして扱うこともできる。

seq の書式の基本は

seq(開始値，終了値，by=変化)

である。3番目の引数を省略すると，±1 刻みで生成される。

練習

以下の式を，R Console で直接入力せよ。（頭の番号は不要）

  1. seq(1, 10)
  2. seq(1, 10, by=0.5)
  3. seq(1, 3, len=21)
  4. x <- seq(1, 3, len=21)
  5. rev(x)
4行
開始値が1，終了値が3，項数が21の数列を作成する。

行列

定義

行列は以下のように定義する。

matrix(c(1, 2, 3, 4, 5, 6), nrow=2, ncol=3)

nrow が行数，ncol が列数，ベクトルが各成分となる。
ここで，連続した値を取るベクトルはコロンを使って，1:6 のように書ける。また nrow と ncol は省略してもよい。これより，上の式は

matrix(1:6, 2, 3)

と書いてもよい。

方向を指定しない場合，先に列方向（下方向）に値が定められる。行方向（右方向）に順に定めたいときは，4番目の引数として byrow=TRUE を指定する。（下の練習の2行目と3行目を参照）

matrix(1:12, 2, 3)

のように値の個数が成分の個数より多い場合は，最初から必要な分だけが割り当てられる。また

matrix(1:3, 2, 3)

のように値の個数が成分の個数より少ない場合は，値が繰り返し割り当てられる。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. matrix(c(1, 2, 3, 4, 5, 6), nrow=2, ncol=3)
  2. matrix(1:6, 2, 3)
  3. matrix(1:6, 2, 3, byrow=TRUE)
  4. matrix(1:12, 2, 3)
  5. matrix(1:3, 2, 3)

演算

行列の演算は以下のようになる。

+ 行列の和
- 行列の差
%*% 行列の積
solve 逆行列
eigen 行列の固有値と固有ベクトル
練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. A <- matrix(1:4, 2, 2)
  2. B <- matrix(c(1, 2, -3, 4), 2, 2)
  3. A; B
  4. A + B
  5. A - B
  6. A %*% B
  7. B %*% A
  8. solve(A)
  9. A %*% solve(A)
3行　セミコロン
1行に複数の関数などを書く場合は，セミコロンで区切る。見難くなる恐れがあるときは，使用しないほうがよい。
6，7行
ベクトルの単元で内積を求めるのに %*% を使ったが，これは行列の積を計算する演算子で，その特別な場合が内積の計算になる。
8行
solve は逆行列を求める関数で，9行目はその確認をするための計算である。

微分

R では関数の微分を計算できる。

Dで微分

関数 expression を用いて式を定義し，D で微分する。D を用いた場合，微分した式を求めることはできるが，その式の値を求めることはできない。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. f <- expression(x^3)
  2. D(f,"x")
  3. g <- expression(sin(x^2))
  4. D(g,"x")
  5. h <- expression(sqrt(x)*sin(x))
  6. D(h,"x")
1行
関数として f を定める。
2行
関数 f を x で微分する。

これら2つの行をまとめて，D(expression(x^3), "x") としても構わない。

derivで微分

上の方法で微分した場合，微分した式を求めることはできるが，その式の値を求めたりすることはできない。関数 deriv を使用すれば値を求めることができる。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. f <- deriv(~x^3, "x", func=TRUE)
  2. f(2)
  3. g <- deriv(~sin(x^2), "x", func=TRUE)
  4. g(2)
  5. h <- deriv(~sqrt(x)*sin(x), "x", func=TRUE)
  6. h(pi/2)
1行
微分した関数を f としている。
2行
x = 2 での元の関数と微分した関数の値を求める。

積分

Rでの積分は，数値積分（定積分で，積分区間が数値になっているもの）のみ可能である。
function で関数を定義し，integrate で数値積分をする。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. f <- function(x) x^2
  2. integrate(f, 0, 1)
  3. g <- function(x) log(x)
  4. integrate(g, 1, exp(1))
  5. h <- function(x) 1/x
  6. integrate(h, 0, 1)
  7. integrate(sin, 0, pi/2)
1行
関数 x2 を f として定義する。
2行
f を積分区間 0 から 1 の間で積分する。この結果
0.3333333 with absolute error < 3.7e-15
と出力されるが，この最後の部分は，誤差の範囲が 3.7×10-15 以下であることを言っている。
6行
積分値が発散するのでエラー表示となる。
7行
既存の関数の積分は，関数名をそのまま使用する。
補足

R では積分した関数を求めるのはできないが，Maxima のような数式処理ソフトを使えば関数を求めることができる。
