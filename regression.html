回帰分析

回帰分析とは

回帰分析とは，線形回帰分析，つまり観測データに「もっとも近い」直線（回帰直線）を見付けて分析や予測を行う方法である。「もっとも近い」とは，観測値と予測値の差の２乗の和が最小になるするとする最小２乗法を用いて求める。（補足資料参照）

以下，東京の気圧と前日の福岡の気圧データを使って，回帰分析を行うので，これをダウンロードして R フォルダに保存する。

データのダウンロード　（ダウンロードは岡山大学内のみ）
出典：中村繁・北村幸房著「気象データマニュアル」理科年表読本，丸善，1987

Rによる分析

分析の手順は以下の通りである。

  1. 変数にデータファイルを読み込む
  2. （必要なら）確認のため，読み込んだ内容を確認する
  3. lm で線形回帰モデルの係数等を求め，変数に代入する
  4. 変数の値を出力する
    （必要なら）summary で詳細な結果を出力する
  5. （グラフが必要な場合は）plot で散布図を描く
  6. （グラフに回帰直線を表示する場合は）abline で先に描いたグラフに回帰直線を追加する
練習

上の操作手順に従って，先にダウンロードしたデータを分析する。

  1. atmos <- read.table('z:\\R\\atmos.csv', header=TRUE, sep=",")
  2. print(atmos)
  3. result <- lm(atmos$東京の気圧 ~ atmos$前日の福岡の気圧)
  4. print(result)　または　summary(result)
  5. plot(atmos$東京の気圧 ~ atmos$前日の福岡の気圧)
  6. abline(result)
lm
線形回帰直線の係数を求める。線形の場合，従属変数と説明変数を ~ で結ぶ。
print
回帰直線の係数と切片のみを表示する。
Intercept：切片
説明変数：係数（傾き）
summary
print よりも詳細な結果を表示する。内容については以下に説明する。

係数の検定

ほとんど相関が無いような分布であっても，回帰分析を行うと係数が計算されてしまう。しかし本当に相関があるのか，つまり回帰分析を行っても良いのかという判断が必要になる。

相関があるか否かは，回帰直線を Y = β1 + β2X としたときに，β2 = 0 であるかを検定することになる。つまり以下のような仮説検定（t検定）を行う。

帰無仮説：β2 = 0
対立仮説：β2 ≠ 0

この検定における t値が t value ，そのt値での両側確率が Pr(>|t|) である。
上で用いたデータの場合，両側確率が 2.03e-05（= 2.03×10-5）となり，有意水準を0.01としても0.05としても，いずれの場合も帰無仮説が棄却されることが分かる。つまりこれらの2つの値には相関があると言ってよい。

正の相関があるか否かを検定するのであれば，上の対立仮説を

対立仮説：β2 > 0

とし，Pr(>|t|) の値の2倍と有意水準を比較すればよい。

その他，Multiple R-squared は相関係数の2乗を表し，この値が1に近いほど相関が強い，つまり回帰直線に近い位置に分布していることを意味する。

重回帰分析

上で行った回帰分析は，1変数から1変数を予測するもので，単回帰分析と呼ばれる。 これと同様の考えで，2つ以上の変数から1変数を予測することも可能である。 これを重回帰分析と呼ぶ。これは単回帰と同様の方法で求めることができる。

分析

以下は日本人学生の身長・体重と足のサイズのデータである。これをダウンロードして R フォルダに保存する。

データのダウンロード　（ダウンロードは岡山大学内のみ）
出典：河内まき子，持丸正明，岩澤洋，三谷誠二（2000）：日本人人体寸法データベース1997-98，通商産業省工業技術院くらしとJISセンター より一部抜粋

次に，以下のRスクリプトを実行する。

  1. data <- read.table('z:\\R\\height_foot.csv', header=TRUE, sep=",")
  2. print(data)
  3. x <- data$身長
  4. y <- data$体重
  5. z <- data$足幅
  6. result <- lm(z ~ x + y)
  7. summary(result)　# または　print(result)

得られた結果は単回帰の場合と同様である。

3D散布図

標準ではできないが，パッケージ rgl を追加することで3次元の散布図を描くことができる。

散布図を描くには，上の分析のスクリプトの後に以下のスクリプトを追加する。

  1. library(rgl)
  2. plot3d(x, y, z)

ここで描かれた図は，マウスでドラッグすれば回転ができる。

この図からも分かるように，例えば2変数から1変数を予測する場合，単回帰分析の回帰直線に相当するものは3次元空間の中の平面となる。上の分析で求めた係数はこの平面を決定するもので，値が大きいほどその変数の影響が大きいことを意味する。
