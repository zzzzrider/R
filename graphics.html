R入門

グラフィックス

ここでは，R を使ったグラフの作成について学ぶ。

plot

plot は座標平面状に点を打って，それを使ってグラフを描くための関数である。plot の基本的な書式は以下の通りである。

書式

plot(横軸の変数，縦軸の変数，type=描画のタイプ, xlab=x軸ラベル, ylab=y軸ラベル, main=グラフタイトル）

type に指定できる値としては，以下のようなものがある。

l（エル） 点の間を直線で結ぶ
p 点のみを描く
h ヒストグラムのように縦棒を描く
練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. x <- seq(-3, 3, len=100)
  2. y <- x^2
  3. plot(x, y, type='l', main='放物線')

さらにこれを以下の通り変更して実行せよ。

  1. 1行の len の値を 10 とする。
  1. 1行の len の値を 10 とする。
  2. type を p とする。
  1. 1行の len の値を 100 に戻す
  2. type を h とする

curve

plot の他に，curve を使っても図形を描ける。curve では，x の範囲や関数を別に定義しておく必要はない。また複数のグラフを同じ平面に描くこともできる。

書式

curve(描画する式，開始値，終了値，値を計算する横軸の個数，add=追加するか否か，type=描画のタイプ, xlab=x軸ラベル, ylab=y軸ラベル, main=グラフタイトル）

add には，グラフを追加する場合，TRUE を指定する。

type に指定できる値は，上の plot と同じである。

練習

以下の式を，R Editor で入力し実行，保存せよ。

curve(x^2, -3, 3, main='放物線')

このように，curve は1行で記述できる。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. curve(sin(x), -2*pi, 2*pi, ylab='y', main='y=sin(x), y=cos(x)')
  2. curve(cos(x), -2*pi, 2*pi, add=TRUE)

このように描くことで，ひとつのキャンパスに複数のグラフを表示できる。

グラフの保存

R で作成したグラフは，PostScript や PNG，JPEG，BMP，TIFF などの形式で保存できる。

描画グラフを直接保存

描画したグラフを右クリックすることで，グラフを保存することができる。直接保存できる形式は，Windows メタファイル（emf）とPostScriptに限られる。ただビットマップにコピーすれば，画像編集ソフトで編集することは可能である。

練習
  1. 上で作成したグラフを右クリックして，ビットマップにコピーを選択する。
  2. Windowsのアクセサリからペイントを起動する。
  3. ペイントで貼り付けを選択する。

PNGで保存

保存処理は，png や postscript などの関数を用いて行う。

保存の流れは以下のようになる。

  1. ファイルやサイズの指定
  2. 画像描画
  3. デバイスを閉じる

具体的には

  1. png（ファイルパス）
  2. plot や curve でグラフを描画
  3. dev.off()

のように書く。さらに，png の書式は次のようになる。

png(ファイルパス，幅，高さ，…）

通常は，ファイルパスだけでよい。

PostScript を除くその他のファイル形式についても，同様に保存できる。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）
その結果，グラフが作成されていることを確認せよ。

  1. png('z:\\R\\parabola.png')
  2. curve(x^2, -3, 3, main='放物線')
  3. dev.off()

補足

ファイル指定は，バックスラッシュ（日本語環境では￥）を2つ入れる。MS Windows ではバックスラッシュ1つしか指定しないので，間違えないように注意すること。

PostScript で保存

PostScript で保存すれば，TeX でそのまま使用することができる。基本的な処理の流れは上のPNGの場合と同じであるが，postscript 関数の使い方が少し異なる。

postscript 関数の書式は次の通りである。

postscript(ファイルパス，family=フォントファミリー，paper=用紙サイズ，width=幅，height=高さ，horizontal=用紙の向き)

図の中で日本語を使う場合，family に Japan1，Japan1HeiMin，Japan1Ryumin などのフォントファミリーを指定しないと正しく表示されない。

width と height はインチで指定する。

horizontal は，TRUE で横置き，FALSE で縦置きになる。

練習

以下の式を，R Editor で入力し実行せよ。（行番号は入力不要）
その結果，グラフが作成されていることと，日本語の表示を確認せよ。

  1. postscript('z:\\R\\parabola.eps', paper='special', width=4, height=4, horizontal=FALSE)
  2. curve(x^2, from='-3', to='3', main='放物線')
  3. dev.off()

このままでは警告が出て，日本語のタイトルが正しく表示されていないことが分かる。

次に postscript に

family='Japan1Ryumin'　（Japan1Ryumin の他に Japan1 や Japan1HeiMin でもよい）

を追加して実行せよ。図でタイトルが正しく表示されていることを確認したら，ソースを保存せよ。

3Dグラフとパッケージ

パッケージとは

関数やデータを分野別に分類してまとめたものがパッケージである。Rには非常に多くのパッケージが用意されており，ほとんどの統計処理は，標準のパッケージ，あるいは適当なパッケージをインストールすることで可能となる。統計処理以外にも，数独のパッケージなどもある。
例えば，パッケージ rgl を追加することで3次元のグラフを描くことができる。

パッケージの追加

パッケージの追加は以下の手順で行う。一度追加したパッケージは再度追加しなくても使用できる。

  1. Rのメニューから　パッケージ　→　パッケージのインストール　を選ぶ。
  2. CRAN のミラーサイトを尋ねられるので，近いサイトを選択する。（日本の大学がよい）
  3. パッケージを選択してインストールする。保存場所はデフォルトのままでよい。

パッケージに含まれる関数一覧は

library(help="パッケージ名")

で調べられる。

練習

3Dグラフを作成するためのパッケージ rgl を追加せよ。

描画

実際に3次元の図を描く例を挙げていく。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）
その結果，グラフが作成されていることを確認せよ。

  1. x <- seq(-3, 3, length=61)
  2. y <- x
  3. f <- function(x, y) {x^2 * y}
  4. z <- outer(x, y, f)
  5. persp(x, y, z, theta=30, phi=20, expand=0.7, col="lightblue")
1，2行
x，yともに-3から3までを60等分した端点の値を持つ数列となる。
3行
関数 x2y を定義する。
4行
(x, y) の各点（61×61個の点）での関数 f の値を z に代入。z は多次元配列となる。
5行
グラフを描画。

グラフが作成されることを確認したら，各数値を変更してその意味を確認せよ。
また関数の定義も変更して，どのようなグラフになるか確認せよ。

この例の persp はパッケージ rgl ではなく標準の graphics ライブラリを使用するので，rgl をインストールしなくても構わない。従って上の例と同様に保存もできる。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）
その結果，グラフが作成されていることを確認せよ。

  1. library(rgl)
  2. x <- seq(-10, 10, length=51)
  3. y <- x
  4. f <- function(x, y) {r <- sqrt(x^2 + y^2); 10 * sin(r) / r}
  5. z <- outer(x, y, f)
  6. persp3d(x, y, z, aspect=c(1,1,0.5), col="lightblue", xlab="X", ylab="Y", zlab="")
1行
パッケージ rgl の読み込みを行う。R のパッケージメニューから［パッケージの読み込み］を選択してもかまわない。一度読み込んだパッケージはRを終了するまで使用出来るので，再度指定しなくてもよい。
2～5行
直前の練習と同じ。
6行
persp3d を使用して3次元グラフを作成する。この関数を使用したグラフは，マウスでドラッグすることで視点の変更ができる。またウィンドウのサイズ変更やスクロールホイールでグラフ自体のサイズ変更もできる。

グラフが作成されることを確認したら，aspect=c(1,1,0.5) の各数値を変更してその意味を確認せよ。
また関数の定義も変更して，どのようなグラフになるか確認せよ。

練習

persp3d でグラフを作成した場合は，以下のいずれかの処理で保存することができる。詳細は ? を使いヘルプを参照すること。

snapshot3d("test.png")
rgl.postscript("test.pdf", "pdf", drawText=FALSE)
