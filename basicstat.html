基本的な統計処理

ここでは，R Editor を使って，Rの基本的な統計処理について学ぶ。

基本統計量

ベクトルの成分を個々のデータとみなして，基本統計量を求めることができる。

max 最大値
min 最小値
median 中央値
range 範囲（最大値と最小値）
sum 合計
mean 平均
var 分散（これは不偏分散と呼ばれるもので，データ数ではなく，データ-1で割ったものになる）
sd 標準偏差（これは不偏標準偏差と呼ばれるもので，データ数ではなく，データ-1で割ったものになる）
cummax k（k = 1, 2, 3, …）番目の項までの最大を続けて表示
cummin k（k = 1, 2, 3, …）番目の項までの最小を続けて表示
cumsum k（k = 1, 2, 3, …）番目の項までの和を続けて表示
cumprod k（k = 1, 2, 3, …）番目の項までの積を続けて表示
練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）

  1. x <- c(-2.2, -2.8, 9.4, 1.5, 6.4, 3.2, -0.3, 8.9, -4.6, 7.3)
  2. max(x)
  3. min(x)
  4. median(x)
  5. range(x)
  6. sum(x)
  7. mean(x)
  8. var(x)
  9. sd(x)
  10. cummax(x)
  11. cummin(x)
  12. cumsum(x)
  13. cumprod(x)

補足

10行目　cummax(x)
1番目の項までの最大値，2番目の項までの最大値，3番目の項までの最大値，…　と順に出力される。以下の cum で始まる関数も同じ。出力されたものはベクトルとして扱われる。
