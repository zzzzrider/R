R入門

ファイル操作

ここでは，R でデータファイルを扱う方法について学ぶ。

CSV形式

ひとつひとつの項目がコンマで区切られたテキストファイルを，CSV形式のファイルと呼ぶ。Rに限らず多くのデータ処理を行うソフトウェアは，CSV形式のファイルを扱うことができる。また，Microsoft Excel やLibreOffice Calc などの表計算ソフトでも，CSVファイルの読み書きができるので，CSVファイルを介してRとのデータのやり取りが可能となる。

CSVファイルの読み込み

CSVファイルの読み込みは，read.csv で行われる。read.csv の書式は以下の通りである。

read.csv(ファイルパス, header = TRUE/FALSE, sep =区切り記号, …)

データファイルに見出しがあるときには，header=TRUE とする。
区切り記号は，例えばデータが :（コロン）で区切られている場合，":" とする。

練習

コンマで区切られた以下のようなデータファイル data1.csv を Z: ドライブの適当なフォルダに作成する。

9.4, 1.8, 5.9, 0.2, 0.0, 9.1, 1.4, 7.1, 3.2, 6.8

次に，以下の関数を実行する。ここでは，CSVファイルは R という名前のフォルダに保存してあることを仮定している。

read.csv('z:\\R\\data1.csv', header=FALSE, sep=",")

これを

x <- read.csv('z:\\R\\data1.csv', header=FALSE, sep=",")

のように，x に代入することもできる。

CSVファイルの書き込み

データをファイルへ書き出すには，write を使用する。write の書式は以下の通りである。

write(ファイルパス, header = TRUE/FALSE, sep =分離記号, …)

write(書き出すデータ, file =ファイルパス, ncolumns =列数, append =追加か否か, sep =区切り文字)

append= の値は TRUE か FALSE で，ファイルの後ろに追加するときに TRUE を指定する。
区切り記号は，例えばデータが :（コロン）で区切られている場合，":" とする。

練習

以下の式を，R Editor で入力し実行，保存せよ。（行番号は入力不要）
実行できたら，ファイルが作成されていることと，その中身を確認せよ。

x <- c(1.2, 3.6, -2.8, 2.0, 3.1, 0.9)
write(x, 'z:\\R\\data2.csv', sep=",", ncolumn=6)
write(c("mean(x)=", mean(x)), 'z:\\R\\data2.csv', append=TRUE)

表の読み込み

表の形式のファイルになっている場合は，read.table で中身を読み込む。read.table の書式は以下の通りである。

read.table(ファイルパス, header = TRUE/FALSE, sep =区切り記号, …)

練習

Microsoft Excel で，下のような表を作成せよ。

氏名 英語 数学 国語
秋田 45 86 57
片岡 36 85 69
橋本 78 64 55
松山 68 31 64

次にこの表を CSV 形式，ファイル名 data3.csv で適当なフォルダに保存せよ。
その後，以下の式を実行せよ。

points = read.table('z:\\R\\data3.csv', header=TRUE, sep=",")
points
sprintf("英語の平均 = %5.1f", mean(points$英語))

補足

sprintf は書式付の出力関数。C 言語の printf と同様に，% で始まる部分に後ろの引数の数値が，桁数指定で入る。
5.1f は，，浮動小数点数（実数のことと考えればよい）を，全体が5桁，小数点以下が1桁になるよう出力するということ。
