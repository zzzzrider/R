R入門

R

R はオープンソースの統計解析ソフトウェアである。 MS Windwos の他に，MacOS X，Linux など様々なプラットフォームの上で動く。

Rのインストール

  1. R の公式Webサイト The R Project for Statistical Computing のトップページ左にある Download, Packages の CRAN から，日本のサイトを選ぶ。
  2. Download R for Windows など，自分の環境にあったものを選択する。
  3. （以下，Windows の場合）base を選択し，Download R 2.**.* for Windows （**.* はバージョン）をダウンロードする。
  4. ダウンロードしたファイルをダブルクリックして，インストールを開始する。

RStudio

RStudio はRの統合開発環境（IDE）である。RStudio には便利な機能が豊富に用意されていて，データファイルの読み込みや内容の確認などが簡単に行えるようになる。

RStudioのインストール

  1. RStudio の公式サイト からページ下部の［DOWNLOAD FREE DESKTOP IDE］をクリックする。
  2. ［RStudio Desktop］から［Free］の［DOWNLOAD］をクリックする。
  3. OSに合ったものをダウンロードする。
  4. ダウンロードしたファイルをダブルクリックして，インストールを開始する。
